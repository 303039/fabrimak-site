# Fabrimak — Corte e Dobra e Corte a Laser

Página institucional estática (HTML + mídia). Publicada no Netlify a partir deste repositório.

- `index.html`: página completa. Número do WhatsApp em `WHATSAPP_NUMBER` no script ao final.
- `media/`: vídeos e fotos reais da Fabrimak.
- `netlify.toml`: publica a raiz do repositório, sem etapa de build.
